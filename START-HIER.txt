📋 NÄCHSTE SCHRITTE (in dieser Reihenfolge):

┌─────────────────────────────────────────────────────────────────┐
│ SCHRITT 1: GitHub Repository erstellen                         │
└─────────────────────────────────────────────────────────────────┘

1. Gehen Sie zu: https://github.com
2. Klicken Sie auf: "+" → "New repository"
3. Name: tesla-tv
4. Privat oder Public wählen
5. WICHTIG: NICHT "Initialize with README" wählen!
6. Klicken Sie "Create repository"

GitHub zeigt Ihnen dann die URL:
https://github.com/coder4nix/TeslaTV.git

KOPIEREN SIE DIESE URL!


┌─────────────────────────────────────────────────────────────────┐
│ SCHRITT 2: Projekt zu GitHub pushen                            │
└─────────────────────────────────────────────────────────────────┘

Öffnen Sie Git Bash im Projekt-Ordner:

  cd C:\Users\ozgr\Documents\tesla-tv

  git remote add origin https://github.com/coder4nix/TeslaTV.git

  git push -u origin master

Falls nach Passwort gefragt:
  - Username: Ihr GitHub Username
  - Password: Verwenden Sie einen Personal Access Token
    (siehe GITHUB-PUSH.md für Anleitung)


┌─────────────────────────────────────────────────────────────────┐
│ SCHRITT 3: Auf VPS installieren (INTERAKTIV!)                  │
└─────────────────────────────────────────────────────────────────┘

SSH Verbindung zu Ihrem Hetzner VPS:

  ssh root@IHR_VPS_IP

Dann auf dem VPS:

  # Installation Script herunterladen
  wget https://raw.githubusercontent.com/IHR_USERNAME/tesla-tv/master/install.sh

  # Ausführbar machen
  chmod +x install.sh

  # Installation starten
  ./install.sh

Das Script fragt Sie INTERAKTIV nach:
  ✓ GitHub Repository URL
  ✓ Domain Name (optional)
  ✓ SSL Zertifikat einrichten? (ja/nein)
  ✓ Email für SSL (optional)
  ✓ Installations-Verzeichnis (Standard: /var/www/tesla-tv)

Sie sehen eine Zusammenfassung und müssen bestätigen.
Dann läuft ALLES automatisch!

Dauer: ca. 5-10 Minuten


┌─────────────────────────────────────────────────────────────────┐
│ SCHRITT 4: Fertig! 🎉                                          │
└─────────────────────────────────────────────────────────────────┘

Nach erfolgreicher Installation:

Ihre App ist verfügbar unter:
  → http://IHR_VPS_IP

Falls Domain konfiguriert:
  → http://your-domain.com
  → https://your-domain.com (mit SSL)

🆘 HILFE BENÖTIGT?

Personal Access Token erstellen:
  → GitHub.com → Settings → Developer settings → Tokens
  → Generate new token (classic)
  → Scope: "repo" auswählen
  → Token kopieren und als Passwort verwenden

SSH Probleme:
  → Siehe GITHUB-PUSH.md Abschnitt "Häufige Probleme"

VPS Installation Probleme:
  → Logs: tail -f /var/log/nginx/tesla-tv-error.log
  → Script erneut ausführen (ist idempotent)
